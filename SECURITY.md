# Security and sensitive reports

For a vulnerability, accidental disclosure or real investigation data, use [GitHub's private vulnerability reporting channel](https://github.com/TENSOR-Standards-Consortium/TENSOR-Website/security/advisories/new). Private vulnerability reporting was enabled on October 11, 2026. Repository administrators receive reports; there is no guaranteed response time, bounty or staffed support service.

For ordinary website defects, open a public issue with the exact URL, source commit, browser, expected behavior and a synthetic reproduction. Do not place credentials, private case bundles or personal data in public issues, screenshots or logs.

For candidate Core specification or validator findings, use the [framework repository's reporting guidance](https://github.com/TENSOR-Standards-Consortium/TENSOR-Framework/blob/main/SECURITY.md). A validation result does not establish evidence truth or authority to act.

The website's Investigation Lab and Studio disable telemetry; imported Lab records remain in browser memory until the visitor downloads an export. Treat imported text and references as data, never as instructions or permission to retrieve or execute anything.
