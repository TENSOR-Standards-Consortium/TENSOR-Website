### TENSOR Core Schema (JSON)

The TENSOR core schema defining the graph format is available as a JSON Schema. The **latest version** of the core schema can be downloaded here: **[tensor.core.schema.json (latest)](https://tensor-standards-consortium.github.io/TENSOR-Framework/releases/core/schemas/latest/tensor.core.schema.json)**.

This schema is used to validate TENSOR investigative graph files (like the [core graph JSON](../graphs/)). Older versions of the schema are available in the TENSOR-Framework repository under the `releases/core/schemas/` directory.
