### TENSOR Core Investigation Graph (JSON)

The TENSOR core investigative graph is available in JSON format. The **latest version** of the core graph definition can be downloaded here: **[tensor.core.graph.json (latest)](https://tensor-standards-consortium.github.io/TENSOR-Framework/releases/core/graphs/latest/tensor.core.graph.json)**.

*Note:* This file follows the TENSOR core schema (see the [Core Schema](../schemas/) for details). Older versions of the graph are archived in the TENSOR-Framework repository under the `releases/core/graphs/` directory.
